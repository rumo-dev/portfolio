## 作品概要

スマートボールとピンボールの要素を融合した、3Dローグライクゲームです。

## 技術的なこだわり

### ピンボール×スマートボールの物理挙動

球体の慣性運動、フリッパーによる弾き、ピン（釘）への衝突時のエネルギー減衰を、数式ベースで正確にシミュレートしました。ローレベルな C++ 実装により、予測可能で爽快感のある物理挙動を担保しています。

### データ駆動型のゲームデザイン

難易度調整やピンの配置データをコードにハードコーディングせず、外部データファイルから動的に読み込む構造を採用。プログラマー以外のメンバーでもパラメータ調整が容易な基盤を設計しました。

### GitHub Flow による堅牢なチーム開発

複数のプログラマーがコンフリクト（衝突）を起こさずに並行開発するため、GitHub Flow を徹底。プルリクエスト運用とコードレビューを挟むことで、常に安定した（ビルドが通る）メインブランチを維持しました。
