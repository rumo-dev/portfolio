## 概要

床や金属面に周囲の形状を映すため、既存のカラーと深度を使うSSRを追加しました。

## 設計判断・処理の流れ

画面内の深度で反射レイを探索し、粗さや金属度で対象を限定します。画面端や距離に応じて寄与を減衰させます。

```text
HDRカラー・G-Buffer・深度 → 半解像度の反射探索 → 反射差分の合成
```

## 実装のポイント

反射方向を投影し、画面上を最大ステップ数で区切って探索します。逆wを用いてレイの深度を透視補正し、深度バッファから復元した値との差が厚みの範囲内ならヒットとします。粗さと金属度による早期除外、Fresnel・画面端・距離による減衰を組み合わせています。

## 制約・検証

画面外・遮蔽された対象は映りません。ステップ上限があるため長いレイでは画素を飛び越える場合があり、薄い形状の欠落やカメラ移動時の不連続は検証が必要です。初期設定ではSSRは無効です。
