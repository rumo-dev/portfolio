## 概要

空間の奥行きと空気中の光を表すため、用途の異なる4方式を用意しました。距離・指数・高さによるフォグと、光の散乱を扱うボリュームフォグを分けて管理しています。

## 設計判断・処理の流れ

距離・指数・高さによるフォグと、空間中の光の散乱を計算するボリュームフォグを別々に扱います。

## 実装のポイント

ボリュームフォグは3Dテクスチャへ光を注入し、視線方向に散乱と透過率を累積して画面へ合成します。現行の初期グリッドは80×48×128です。割当済みサイズを保持し、処理側もそのサイズに合わせます。FogBaseの共通インターフェースを持ち、Post_Process_Managerの4項目として扱います。

### 現行コードの抜粋

```cpp
    int   grid_width = 80;
    int   grid_height = 48;
    int   grid_depth = 128;
    int   pad_grid = 0;
```

## 制約・検証

低解像度のボリュームを補間するため、薄い光の筋や境界の表現に限界があります。密度・散乱・吸収・光源数による見た目と処理時間は、同じカメラと露出で比較する必要があります。
