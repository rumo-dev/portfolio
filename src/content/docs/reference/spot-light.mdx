## 概要

懐中電灯のように向きと広がりを持つ光を表すため、点光源の位置・半径・光量に加え、方向と内外2つの角度を持たせています。

## 設計判断・処理の流れ

コーンの内外の角度による減衰と、距離による減衰を組み合わせます。寄与がゼロになる場合は後続のBRDF評価を省略します。

## 実装のポイント

光源からの方向とライトの向きの内積を、内外の角度のcosと比較します。外側より外ではゼロ、内側では1、その間をsmoothstepで補間し、コーン境界の光量を滑らかにします。現在のシェーダーでは角度のcosを照明ループ内で算出しています。

距離減衰は半径でゼロになるcutoffに、距離の二乗と近距離の安定化項を組み合わせます。角度減衰との積がゼロなら、後続のBRDF評価を省略します。

SpotLightManagerは点光源と同様にカリングとDynamic StructuredBufferによる転送を担当します。照明用のStructuredBufferはt9、光源数の定数バッファはb6で参照します。

### 現行コードの抜粋

```hlsl
        float distanceCutoff = pow(max(0.0f, 1.0f - pow(dist / spotLights[spotLightIndex].radius, 4.0)), 2.0f);
        float distanceAttenuation = distanceCutoff / (683.0 * (dist * dist + 0.04));
        float totalAttenuation = spotAttenuation * distanceAttenuation;

        if (totalAttenuation <= 0.0f)
        {
            continue;
        }
```

## 制約・検証

コーン境界、光源に近い位置、照射半径の端で見た目が連続するかを確認します。スポットライトの照明を扱うことと、専用シャドウマップの実装範囲は別に評価します。
