## 概要

平行光にはライト視点の直交投影、点光源には前後2方向の双放物面マッピングを使います。点光源1灯だけという旧構成から、タイルを割り当てる構成へ変更しています。

## 設計判断・処理の流れ

光源の種類に応じて投影方式を変えます。点光源は前後2枚の深度テクスチャをタイルに分け、複数ライトの影を格納します。

## 実装のポイント

前後の深度テクスチャはそれぞれ2048×2048で、4×4に区切って最大16灯分のタイルを持ちます。cast_shadowsと容量に応じてshadow_tileを割り当て、Scene_Indoorから対象ライトの前面・背面を描画します。サンプル時はタイルの余白を考慮し、前後の境界付近では両側の結果を補間します。深度リソースはR24G8_TYPELESSです。

### 現行コードの抜粋

```hlsl
float2 PointShadowAtlasUV(float2 uv, int shadow_tile)
{
    const float atlas_grid = 4.0f;
    const float atlas_size = 2048.0f;
    const float tile_padding = 2.0f / atlas_size;
    uint tile_index = (uint)shadow_tile;
    float2 tile = float2(tile_index % 4u, tile_index / 4u);
    return tile / atlas_grid + tile_padding + uv * (1.0f / atlas_grid - 2.0f * tile_padding);
}
```

## 制約・検証

全ライト1024灯の管理上限と、影の16タイルは別の上限です。タイルごとの解像度、深度バイアス、前後の継ぎ目に画質上の制約があります。照明の種類に対応していることと、各種類の専用シャドウマップを生成することも区別しています。
