## 概要

家具と床、壁の隅に接地感を与えるため、直接光の影とは別に画面空間の遮蔽を導入しました。

## 設計判断・処理の流れ

G-Bufferの位置・法線を再利用し、半解像度の計算結果を輪郭に配慮したフィルタで合成へつなぎます。

```text
G-Bufferの位置・法線 → 半解像度AO → 水平・垂直クロスバイラテラル → フル解像度へのアップサンプル → ライティング
```

## 実装のポイント

各画素で円盤上の24点を参照します。カメラ空間の深度に合わせて探索半径をUVへ変換し、画素ごとの回転でサンプルパターンを分散します。半解像度の計算結果を位置情報でフィルタし、輪郭をまたぐにじみを抑える構成です。

### 現行コードの抜粋

```hlsl
    const int sample_count = 24;
    const float radius = max(ssao_radius, 1.0e-3f);

    float3 position = mul(float4(center_position.xyz, 1.0f), view).xyz;
    float3 normal = normalize(mul(float4(world_normal, 0.0f), view).xyz);
    float rotation = hash_pixel(pin.position.xy) * 6.2831853f;
    // Alchemy samples a disk parallel to the image plane. Project the
    // world-space radius at this pixel's camera-space depth to UV units.
```

## 制約・検証

画面外や裏側の形状による遮蔽は得られません。G-Buffer位置のアルファを背景判定にも使うため、AO値がほぼゼロの材質との区別は今後の検証点です。
