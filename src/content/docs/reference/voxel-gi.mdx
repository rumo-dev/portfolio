## 概要

静的な室内モデルから放射輝度をボクセルへベイクし、間接光として再利用するVoxel GIを追加しました。これは動的な全シーンGIではなく、選択した静的モデルを明示的に再ベイクする方式です。

## 設計判断・処理の流れ

対象モデルを一度ボクセル化し、通常の描画ではボリュームを参照します。再ベイクが必要な静的データと、毎フレーム変わるシーン光源を分けることで、ボクセルデータの役割を明確にしています。

```text
静的glTFモデル → 32³〜256³ボリュームへ材質・法線・放射輝度を記録（初期値64³）
              → mip生成 → 画素ごとに5方向のコーントレース
              → 拡散間接光としてDeferred Lightingへ加算
```

## 実装のポイント

室内シーンの`Library`モデルを初回描画時に`R16G16B16A16_FLOAT`ボリュームへベイクします。解像度は32³、64³、128³、192³、256³から選べ、初期値は64³です。解像度の変更時にはボリュームを再生成して再ベイクします。発光材質と環境フィルを放射輝度に含め、ベイク後にミップを生成します。Deferred Lightingでは可視画素ごとに5本のコーンを追跡し、拡散照明へ加算します。

ベイク済みボリュームには材質アルベドと法線も保存します。これらは後段のDDGIがボクセルヒット位置で現在のシーン光源を評価するために使います。

## 制約・検証

ボリュームは静的モデルだけを対象とし、動的ライトやシャドウマップはベイクに含めません。薄い面では光漏れが起きる場合があります。解像度・環境フィル・発光倍率・ベイク対象を変えた場合は再ベイクし、SSGIを無効にしてVoxel GI単体の寄与を確認します。
