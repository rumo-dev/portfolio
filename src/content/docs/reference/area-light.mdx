## 概要

窓やパネルの広がりを持つ光を扱うため、LTCによる面光源の近似を組み込みました。

## 設計判断・処理の流れ

粗さと視線角からLTCの行列・振幅を参照し、光源の面積にわたる反射を近似します。

```text
粗さ・N·V → 行列LUTと振幅LUT → 光源頂点の変換 → エッジ積分 → 拡散・鏡面反射
```

## 実装のポイント

LTC_Lookupは粗さとsqrt(1−N·V)からUVを作り、64×64 LUTのテクセル中心へ補正します。行列をt11、振幅をt12で参照し、鏡面成分では変換後の光源形状を評価します。現行実装はTextureless方式ではありません。

### 現行コードの抜粋

```hlsl
void LTC_Lookup(float roughness, float NoV, out float4 matrixData, out float4 amplitudeData)
{
  float2 uv = float2(saturate(roughness), sqrt(saturate(1.0 - NoV)));
  uv = uv * ((LTC_LUT_SIZE - 1.0) / LTC_LUT_SIZE) + (0.5 / LTC_LUT_SIZE);
  matrixData = ltcMatrixLut.SampleLevel(sampler_states[LINEAR_CLAMP], uv, 0);
  amplitudeData = ltcAmplitudeLut.SampleLevel(sampler_states[LINEAR_CLAMP], uv, 0);
}

```

## 制約・検証

LTCはBRDFの近似で、物理的に厳密な積分ではありません。形状や粗さ、視点で見え方を検証する必要があります。光の広がりとソフトシャドウは別の問題として評価します。
