## 概要

画質と描画負荷を調整できるよう、DLSSの呼び出しだけでなく内部解像度の変更を描画基盤へ組み込みました。

## 処理フロー図

```mermaid
flowchart LR
  A["カラー・深度・速度を用意"]
  A --> B["利用可能なNGX機能を確認"]
  B --> C["選択したDLSSモードで評価"]
  C --> D["出力解像度の画像を取得"]
```

## 設計判断・処理の流れ

NGXの呼び出しと描画側のリソース管理を分け、内部解像度が変わった場合も入力と履歴の整合性を保ちます。

```text
内部解像度のジオメトリ・照明 → カラー・深度・速度 → NGX評価 → 出力解像度の画像
```

## 実装のポイント

DLSSManagerが初期化、機能生成、モード変更、リソース解放を担当します。Ultra Performance、Performance、Balanced、Quality、DLAAのモードを定義しています。内部解像度の変更時はG-Buffer、SSAO、SSR、SSGI、TAA履歴などを再生成します。

## 制約・検証

実行環境とNGXの利用可否に依存します。IsAvailableと失敗理由を公開し、使えない状況を判別できる設計です。モードごとの実測FPSや画質比較は未掲載で、すべての環境での動作を保証するものではありません。
