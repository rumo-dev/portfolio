## 概要

カメラの焦点距離、F値、合焦距離から錯乱円（CoC）を求め、ピント面から外れた領域をぼかします。

## 設計判断・処理の流れ

CoCに応じて寄与をScatterし、累積和とResolveでボケ画像を構築します。フィルタ半径に対する処理量を抑える構成です。

```text
深度 → Near/Far CoC → 単一デルタバッファへのScatter → 水平・垂直の累積和 → Resolve → Composite
```

## 実装のポイント

現行版はNear/Far用の2画像を個別にぼかす構成から変わり、符号付きCoCを使って全画素の寄与を単一デルタバッファへ蓄積します。Compute ShaderのInterlockedAddで固定小数点を加算し、Resolveで重みを正規化した完成画像を作ります。最終Compositeでフル解像度へ出力します。

## 制約・検証

フィルタ半径に対する仕事量を抑える設計ですが、解像度・アトミック競合・メモリ帯域には依存します。処理全体がO(1)であるという意味ではありません。Near CoC、Far CoC、FFS結果、焦点範囲の表示で境界の挙動を確認します。
