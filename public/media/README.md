# ポートフォリオの画像・比較素材

`atmosfiore-indoor.jpg` は AtmosFiore を実行して撮影した 1920×1080 の Indoor シーンです。作品全体の実行画面として使用し、機能別のON/OFF比較には流用しません。

placeholder-before.svg / placeholder-after.svg はレイアウト確認用の仮画像です。実装結果ではありません。

実画像は機能別に media/ssao-before.webp のような名前で配置し、記事の FeatureMedia に beforeImage と afterImage を指定してください。URLには /portfolio/ を含めます。2枚の解像度と画角を揃え、露出・ライト・カメラ条件を固定してください。実画像へ交換したら、FeatureMedia の仮画像見出しとキャプションも更新します。

公開済みの動画は各作品ページの ModalVideo の videoId で指定しています。自動再生は行いません。
